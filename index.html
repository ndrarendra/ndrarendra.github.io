Featured Projects

Project 01

Change Data Capture Pipeline

A real-time pipeline that captures every data change in a MySQL database and streams it downstream. Debezium reads from the binary log and publishes events to Kafka, which are then indexed in Elasticsearch and visualized in Kibana. A lightweight Flask interface provides a live view of incoming changes without requiring direct access to Kafka consumers. The full stack (six services) runs from a single Docker Compose file.

Project 02

Multilingual RAG System

A retrieval-augmented generation system built and tested across two model backends: Ollama with LLaMA for fully local inference, and GPT via the OpenAI API. Both were evaluated against English and Korean document sets. Korean support was a genuine requirement from the outset, and comparing retrieval quality across both languages produced results that informed how I approached the final architecture. Built with Python, no external frameworks.
